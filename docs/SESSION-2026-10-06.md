## Decisions Made
- Encourage, never punish: no lives, no leaderboards, and scripture is never locked.
- Game rules are pure functions in `lib/game.ts`. `mutate()` is the single write path for XP and celebrations, and every XP source has a daily cap.
- Questions come from a curated bank, not AI. Each one cites a BSB verse and is checked by `scripts/verify-trivia.ts`.
- Seeds come from play counts, so there's no `Math.random()` during render.
- The repo is private. The sales page makes no pricing claims.

## Key Learnings
- GSAP absorbs a CSS `translate` on the element it animates and lost `-100%`. Keep CSS anchoring on a wrapper and animate an inner element.
- `Math.sin()` differs between Node and the browser in the last digits. Round SVG coordinates to avoid hydration mismatches.
- Background or hidden tabs pause `requestAnimationFrame`, so GSAP tweens freeze. Test animation in the foreground.
- API.Bible JSON splits verses into text runs that can be missing a joining space.
- `.ring` is a Tailwind utility class, so don't use it for a custom class.
- Recraft can't count small repeated items (stars, lampstands). Fix those in post.
- Pilgrim face consistency works with Seedream 5 Pro and an `image` reference.
