# Selah

A quiet Bible study web app: read in six translations, search, highlight, take notes, and follow reading plans.

## Setup

```bash
cp .env.example .env.local   # then add your API.Bible key
npm install
npm run dev
```

Get a key at https://scripture.api.bible. Highlights and notes are stored in the browser (export them from the Notes page).
